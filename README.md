## 线路架构：广州入口、香港出口和双独立 IP

广港IEPL 的链路是“广州入口 → 香港出口”的点对点专线：流量从广州机房进专线，到香港再走 BGP 出口访问目标，中间段不过公网。1–2ms 的内网延迟就是这么来的。

入口值得单独说。2023 年批次走 UCloud 广州 BGP，2026 年春节档换成腾讯广州八线 BGP。八线接入意味着电信、联通、移动的用户连入口的质量更一致，晚高峰体验的差异主要就看这一段。

出口挂在香港 Nearoute Limited（AS147293）名下，IP 落在荃湾机房，是广播型 IDC 机房 IP。2023 年 12 月一份第三方测评的 IP 质量结果比较分裂：Scamalytics 欺诈评分 0/100（低风险），IPQualityScore 给到 65/100（中等），ping0 标了 41% 的 SSH 爆破风险可能性。整体算“干净度中等、IDC 属性明显”。远程办公、游戏加速、开发测试这类用途不受影响，对 IP 纯度极度敏感的业务自己掂量。

带宽跑满度也有数据可查：150Mbps 档单线程在香港本地节点测出 131–135Mbps，接近标称值；到台湾 99–129Mbps，东京 104–126Mbps，美西 96–104Mbps。个别美东节点波动很大（Leaseweb 华盛顿只跑出 3.62Mbps），那是落地机到美国东部的公网段表现，和专线内网无关。

硬件属于“够用”级别：2023 年那台 1核2G 机器是 AMD EPYC 7402P 平台，KVM 虚拟化，磁盘平均 I/O 约 304 MB/s，内核默认 BBR。对一台跑专线转发的路由机来说这些参数不构成瓶颈，真正决定体验的始终是带宽和线路。

双独立 IP 是这套产品的招牌：每个套餐两个 IPv4，入口一个、出口一个。实际用途集中在入口出口流量分离、指定出口 IP 的定向转发，以及把远程管理的连接和落地访问拆开。顺带提醒一句 IPv6：2023 年测评的套餐开机时 IPv6 显示离线，不同批次支持情况不一致，在意的话下单前直接问客服。

## 下单前必须确认的四条限制

Mkcloud 专线和普通 VPS 的差别，一半写在条款里。以下四条来自官方条款和产品说明，逐条对完再付款。

1. **国内实名。** 专线需要国内手机号实名认证，付款支持支付宝。没有国内手机号，流程走不通。
2. **省级白名单。** 接入 IP 只允许落在一个省份，开通时就要选定；之后可以申请换省，但任何时刻只有一个省在线，不支持多省同时接入。
3. **用途红线。** 条款写明只允许合法的个人或企业用途，禁止代理、中转等非合规用途。
4. **退款门槛。** 只有确认的质量问题才退款，且要提交详细的延迟和测速数据作证据；激活后不支持转成其他地区的产品。

把话挑明：如果你的场景需要在多个省份切换接入，或者用途就是代理节点，这款产品在条款层面就把你排除在外了，不用再往下比价格。

> 省份白名单是不少人付款后才反应过来的限制：入口位置开通即锁定，换省要走申请。人在两地频繁跑的，先想清楚主要在哪个省接入。

## 常见问题

**广港IEPL 和沪日IPLC 怎么选？**
看业务方向。只求香港超低延迟（内网段 1–2ms）选广港；做日本市场或中日之间传数据，选沪日（内网段 25–28ms）。

**双独立 IP 实际能干什么？**
入口出口各一个 IPv4，可以做流量分离、指定出口 IP 的定向转发，也能把远程管理连接和落地访问拆开管理。

**开通后能换接入省份吗？**
能申请，但一次只有一个省生效，不支持多省同时接入。

**没有国内手机号能买吗？**
不能，实名认证是硬性前提。

**退款好退吗？**
不好退。只认质量问题，且必须附延迟和测速数据。收货当天先做一轮测速并截图留存，万一出问题，这些就是举证材料。
